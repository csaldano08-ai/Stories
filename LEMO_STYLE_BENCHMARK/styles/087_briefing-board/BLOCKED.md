BLOCKED. STYLE.md §1.2: "Real things on it: cut-out photographs of the real objects… They are evidence: never a generated image presented as a real object." §10 names the sources: Wikimedia Commons, national libraries and archives, agency media pages, Flickr Commons.

The board is built from photographs of real objects (a wristwatch, a station clock, a rain puddle, a train ticket, a coat), and the library ships none (the demo fetches them in its tools). Every photo host the style names answers `403 (agent proxy: no rule allows this host)`: `upload.wikimedia.org`, `commons.wikimedia.org`, `tile.loc.gov`, `www.loc.gov`, `api.smithsonian.edu`, `www.rijksmuseum.nl`. Drawing the objects in code or rendering 3D models and calling them photographs would break the style's rule; it is not replaced by a generic version.
